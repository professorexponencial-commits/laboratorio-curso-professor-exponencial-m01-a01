# Laboratório do Curso Professor Exponencial — Módulo 01 · Aula 01

**O Mercado Não Reconhece Quem Não Consegue Enxergar**

Esta página contém somente o laboratório interativo desta aula; não contém uma lista de módulos.

Endereço público esperado: https://professorexponencial-commits.github.io/laboratorio-curso-professor-exponencial-m01-a01/

## Publicação no GitHub Pages

1. Criar o repositório público **laboratorio-curso-professor-exponencial-m01-a01** no perfil **professorexponencial-commits**.
2. Enviar **somente o conteúdo extraído de 01_PUBLICAR_NO_GITHUB** para a raiz.
3. O arquivo principal deve estar na raiz como `index.html` (nunca `index (1).html`).
4. Configurar Settings > Pages > Deploy from a branch > main > /(root) > Save.
5. Testar o endereço público; conferir também se o logo e a imagem carregam.
6. Só depois colocar o código `02_CODIGO_HOTMART/01_CODIGO_FONTE_COPIAR_HOTMART.txt` na Hotmart.

## Identidade

Logo oficial com fundo branco e original com fundo preto arquivados. A atividade preserva fundo claro.

## Progresso do professor

Os registros são armazenados **localmente no navegador** e podem ser salvos em backup. O professor deve criar uma pasta chamada **Laboratório do Professor Exponencial** para guardar os cadernos de cada aula.

Os PDFs do mapa mental e das anotações devem ser anexados na Hotmart; não foram colocados no ZIP público do GitHub.
